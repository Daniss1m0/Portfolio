# Portfolio

This project is a personal **developer portfolio website** built with **Next.js (App Router)**, **React**, and **Tailwind CSS**.

🔗 **Live:** [daniildunytskyi.vercel.app](https://daniildunytskyi.vercel.app/)

## Features

* **Project Showcase** — Interactive cards featuring game development, VR, and graphics projects with direct links to source code
* **Profile Section** — Highlights technical skill set (C++, C#, Unity, UE5, OpenGL)
* **Dark Minimalist UI** — Clean, responsive design optimized for mobile and desktop screens
* **Fast Performance & SEO** — Fully configured Open Graph metadata and rapid page delivery
* **CI/CD Deployment** — Seamless automated deployment with Vercel
